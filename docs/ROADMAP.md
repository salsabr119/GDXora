# خارطة الطريق · Roadmap

> آخر تحديث: 2026-09-27

## ✅ الإصدار 0.1 — الأساس (منجز)

- المنصة متعددة الشركات: عزل كامل بين الشركات بـ RLS، وأدوار وصلاحيات، وسجل تدقيق، وتسجيل ذاتي يجهّز الشركة تلقائياً.
- المحاسبة: دليل حسابات، قيود، ميزان مراجعة، قوائم مالية، كشوف حسابات، فترات مالية.
- الفوترة مع ZATCA (المرحلة الأولى): فواتير وإشعارات، QR، XML، بصمة، سلسلة ICV/PIH.
- المشاريع: جدول الكميات (BOQ)، المستخلصات، المحتجزات، الدفعات المقدمة، الربحية.
- المالية: الموردون، فواتير الموردين، السندات، أعمار الذمم، الإقرار الضريبي.
- الموارد البشرية والرواتب: الإجازات، التأمينات، مسيّر الرواتب، نهاية الخدمة، ملف البنك.
- الربط: REST API ومفاتيح لكل شركة، Webhooks موقّعة، مواصفات OpenAPI.
- الاختبارات:
  - 25 اختبار وحدة.
  - اختبارات SQL شاملة.
  - اختبار شامل (e2e) على Supabase حقيقي.
  - اختبار واجهة بالمتصفح.

## الإصدار 0.2 — الجاهزية للتشغيل الفعلي في شركتك

- [ ] ZATCA المرحلة الثانية: تسجيل CSID، التوقيع الرقمي، إرسال الفواتير للتبليغ أو الاعتماد (انظر `docs/ZATCA.md`).
- [ ] طباعة PDF بقالب الشركة وشعارها، وإرسال الفاتورة للعميل بالبريد.
- [ ] استيراد من Excel: دليل الحسابات، العملاء، الموظفين، الأرصدة الافتتاحية.
- [ ] قيد إقفال السنة المالية وترحيل الأرباح المبقاة.
- [ ] مخصص نهاية الخدمة الشهري (قيد آلي)، وتسوية نهائية للموظف المنتهية خدمته.
- [ ] دعوة المستخدمين بالبريد (`/api/members/invite`) بدل اشتراط أن يسجّلوا أولاً.
- [ ] مرفقات للمستندات (Supabase Storage): العقود، فواتير الموردين، المستندات الرسمية.

## الإصدار 0.3 — توسعة الوحدات

- [ ] أوامر الشراء، وطلبات الشراء، والمطابقة مع فواتير الموردين.
- [ ] عروض الأسعار، وتحويل العرض المقبول إلى عقد أو مشروع.
- [ ] الحضور والانصراف، وجداول ساعات العمل على المشاريع (timesheets) لتحميل تكلفة العمالة بدقة.
- [ ] الأصول الثابتة والإهلاك.
- [ ] الموازنات التقديرية ومقارنتها بالفعلي.
- [ ] تسوية الحسابات البنكية، واستيراد كشوف الحسابات.
- [ ] أنظمة حكومية: ملف حماية الأجور (مُدد) بالصيغة الرسمية، والتأمينات الاجتماعية.

## الإصدار 1.0 — الطرح التجاري (SaaS)

- [ ] الباقات والاشتراكات: جدول `plans`، وحدود الاستخدام، وتفعيل الوحدات حسب الباقة (جدول `org_modules` جاهز).
- [ ] بوابة دفع للاشتراكات: Moyasar أو Tap أو HyperPay.
- [ ] لوحة مالك المنصة: الشركات، الاشتراكات، الاستخدام، الدعم الفني.
- [ ] صفحة تعريفية وموقع تسويقي، وتجربة مجانية.
- [ ] الامتثال لنظام حماية البيانات الشخصية (PDPL):
  - سياسة خصوصية.
  - تصدير بيانات الشركة كاملة.
  - خيار استضافة داخل المملكة.
- [ ] مراقبة التشغيل: تتبع الأخطاء، ونسخ احتياطي يومي، والاستعادة لنقطة زمنية (PITR).
- [ ] تطبيق جوال (PWA/Capacitor) يعمل على نفس الـ API.
- [ ] موصّلات جاهزة: Foodics، Salla/Zid، البنوك، Power BI.
